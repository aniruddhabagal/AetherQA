Capabilities

Everything your QA team needs.
Nothing they don't.

Six capabilities, tightly integrated into a single pipeline. Each learns from every run.

Autonomous Exploration

Crawls your app with a real browser, captures accessibility trees, intercepts API calls, and detects voice inputs, file uploads, and infinite scroll.

Spec Generation

Generates human-readable Markdown test specs with edge cases, preconditions, and expected outcomes. Your QA team reviews before any code runs.

Playwright Code Gen

Writes real Playwright TypeScript tests from approved specs. Three templates — UI, voice, and API — run immediately and stream results live.

Self-Healing Tests

When selectors break after a deploy, the Maintenance agent reads your source from GitHub, finds the new selector, patches the test, and re-runs it.

Voice & Mic Testing

Mocks Web Speech API and getUserMedia. Tests happy paths and all error states — permission denied, no speech, network errors, silence, background noise.

Persistent Memory

Learns from every run via Mem0. Remembers app structure, heal patterns, known bugs, and QA preferences. Gets measurably smarter over time.

Architecture

Five agents. One pipeline.

Each agent is a LangGraph subgraph with its own memory scope. They read context before acting and write learnings back after.

0

Scoper

Parses feature description, reads git diff via GitHub MCP, maps direct scope + blast radius.

Feature mode only
1

Explorer

Crawls scoped routes with Playwright, captures accessibility trees, intercepts network calls, reads React Router config from source.

2

Test Case

Generates Markdown specs with edge cases derived from your real Zod schemas. Pipeline pauses for human review.

Human checkpoint
3

Automation

Writes Playwright .spec.ts files from approved specs. Runs them across parallel workers. Streams results live via SSE.

4

Maintenance

Triages failures, self-heals broken selectors using component source, quarantines flaky tests, escalates real bugs.

Runs in parallel
5

API Tester

Fetches OpenAPI spec, diffs against last run, generates contract + auth + validation tests for every endpoint.

Workflow

From trigger to results in minutes.

01

Trigger a run

Choose full regression, smoke, or feature mode. Describe the feature in plain English. Hit start.

02

Review AI specs

The system generates test specs and pauses. Your QA team reviews, edits edge cases, and approves.

03

Watch tests run

Live SSE streaming shows each test as it passes or fails. Voice, UI, and API tests run together.

04

Triage what matters

Broken selectors heal automatically. Real bugs surface with AI diagnosis, screenshots, and reproduction commands.
