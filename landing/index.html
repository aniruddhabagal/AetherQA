Autonomous QA System

QA that writes tests,
runs them, and heals itself.

AetherQA is a five-agent pipeline that crawls your app, generates test specs, writes Playwright scripts, self-heals broken selectors, and gets smarter every run through persistent memory.

Capabilities

Everything your QA team needs.
Nothing they don't.

Autonomous Exploration

Crawls your app with a real browser, captures accessibility trees, intercepts API calls, and detects voice inputs, file uploads, and infinite scroll.

Spec Generation

Generates human-readable Markdown test specs with edge cases, preconditions, and expected outcomes. Your QA team reviews and approves before any code runs.

Playwright Code Gen

Writes real Playwright TypeScript tests from approved specs. Three templates: UI, voice, and API. Runs them immediately and streams results to your dashboard.

Self-Healing Tests

When selectors break after a deploy, the Maintenance agent reads your React source from GitHub, finds the new selector, patches the test, and re-runs it.

Voice & Mic Testing

Mocks Web Speech API and getUserMedia. Tests happy paths, error states (permission denied, no speech, network error), and edge inputs like silence or background noise.

Persistent Memory

Learns from every run via Mem0. Remembers your app structure, successful heal patterns, known bugs, and QA preferences. Gets measurably smarter over time.

Architecture

Five agents. One pipeline.

Each agent is a LangGraph subgraph with its own memory scope. They read context from Mem0 before acting and write learnings back after.

0

Automation

4

Runs in parallel
5

Fetches OpenAPI spec, diffs against last run, generates contract + auth + validation tests for every endpoint.

Workflow

From trigger to results in minutes.

01

Trigger a run

Choose full regression, smoke, or feature mode. Describe the feature in plain English. Hit start.

02

Review AI specs

The system generates test specs and pauses. Your QA team reviews, edits edge cases, and approves.

03

Watch tests run

Live SSE streaming shows each test as it passes or fails. Voice tests, UI tests, and API tests run together.

04

Triage what matters

Broken selectors get healed automatically. Real bugs surface with AI diagnosis, screenshots, and curl commands to reproduce.
